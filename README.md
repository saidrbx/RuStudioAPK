<p>
  A native Android port of
  <img src="docs/pictures/rustudio.png" width="20" height="20" align="center" /> <a href="https://github.com/rippelz/rustudio">Rustudio</a>,
  a native editor for Roblox places, written in Rust. 
</p>

> [!WARNING]
> RuStudioAPK is an unofficial, community-developed project that brings the **Rustudio** editing experience to Android, allowing users to work with Roblox place files directly on ARM64 devices running Android 8.0 or later. It is not affiliated with, endorsed by, sponsored by, or officially associated with Roblox Corporation. If you have any suggestions for UI improvements or other Studio-related features, feel free to share them — your feedback is always welcome and helps make the project better!

## Build

Install JDK 17, Android SDK Platform 35, Build Tools 35.0.0, NDK 29.0.14206865, and Rust with rustup. Set `ANDROID_HOME` to your SDK directory or open the project in Android Studio.

```sh
rustup target add aarch64-linux-android
cargo install cargo-ndk --version 4.1.2 --locked
```

| Host | Command from the repository root |
| --- | --- |
| <img src="docs/pictures/linux.png" width="20" height="20" align="center" /> Linux | `./gradlew assembleDebug` |
| <img src="docs/pictures/windows-11.png" width="20" height="20" align="center" /> Windows | `.\gradlew.bat assembleDebug` |

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`. See the [build guide](docs/android/BUILD.md) for setup details, GitHub Actions, and signing.

## Reporting Issues
When reporting a problem, please include:
- RuStudioAPK version.
- Android version.
- Device model.
- Steps to reproduce the issue.
- Screenshots or additional details, if applicable.

You can export diagnostic information directly from the editor:

**Menu → Help → Share Diagnostic Logs**

Review the exported logs before sharing them to ensure they do not contain sensitive information.

For additional instructions, see the [Usage Guide](docs/android/USAGE.md).
